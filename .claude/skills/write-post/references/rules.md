# 공개·개인정보·발행 게이트

근거: 지피터스 SEO·GEO 플레이북, 2026-09-18 사례글 222편 분석(`seo-geo-brief.md`), 발행 점검표. 스터디 멤버용으로 2026-09-23 정리.

## 1. 링크

본문, 이미지 alt, 캡션, 코드블록 어디에도 **남이 못 여는 주소**는 0건. 발견하면 링크를 지우고 "제 노션 페이지", "로컬에서 띄운 화면"처럼 말로 바꾼다.

- 차단: `localhost`·`127.0.0.1`·서버 IP·포트 번호가 붙은 주소, 채팅방·그룹 ID, 로그인해야 열리는 주소(지피터스 학습시스템 `ai-study.gpters.org`, 슬랙 워크스페이스, 회사 사내 도구, 관리자 화면), 주소에 `token=`·`key=`가 붙은 것.
- 확인: 노션·에어테이블·구글 문서 링크는 **공개 설정인지 먼저 묻는다.** 공개면 남기고, 아니면 뺀다.
- 권장: 내가 만든 공개 결과물(배포한 웹앱, 공개 GitHub, 유튜브, 공개 노션). 독자가 눌러 볼 수 있는 결과물은 글의 신뢰를 올린다.
- 키·토큰이 붙은 주소는 일반화하지 않고 통째로 삭제한다.
- 사용자 이름이 든 절대 경로(`/Users/이름/...`, `C:\Users\이름\...`) 금지. `~/Desktop/내폴더`처럼 쓴다.

## 2. 이미지 블러

- 가리는 것: 사용자 이름이 든 폴더 경로, 이메일·전화번호·주소, API 키·토큰, 고객·거래처·동료의 이름과 연락처, 회사 사내 주소가 보이는 주소창.
- **가리지 않는 것: 본인 지피터스 닉네임과 프로필 사진.** 과하게 가리면 글이 가짜처럼 보인다.
- 멤버가 좌표를 찍지 않는다. 스킬이 캡처를 열어 보고 가릴 후보를 번호로 묻는다. "① 왼쪽 위 폴더 경로 ② 오른쪽 거래처 이름, 이 두 곳 가릴까요?" 승인받은 것만 가린다. 후보가 없으면 "가릴 게 안 보여요. 놓친 게 있으면 알려 주세요"라고 한 번 묻는다.
- 방법: 주소창처럼 위치가 고정된 건 `--crop-top`으로 잘라내고, 본문에 섞인 건 `scripts/blur-region.py`로 픽셀화+블러. Pillow·ImageMagick이 둘 다 없으면 "이 부분은 직접 가려서 다시 주세요"라고 위치를 말로 알려준다.
- 가린 결과를 다시 열어 보고 "이렇게 가렸어요"로 보여준다.

## 3. 숫자

- **내 숫자를 공개할지는 본인이 정한다.** 가게 매출, 내 수입, 구독자 수처럼 본인 것은 묻고 쓴다. "매출은 어림수로 쓸까요, 뺄까요?"
- 작업 측정치(걸린 시간, 파일 수, 재시도 횟수, 토큰, "전에는 하루 걸렸다")는 내부 숫자가 아니다. 묻지 않고 쓴다.
- 회사원이면 회사 내부 숫자(매출, 고객 수, 계약 조건, 내부 KPI)는 쓰지 않는다. 쓰고 싶다고 하면 "회사에 공개해도 되는지 확인하셨어요?"를 한 번 묻고, 애매하면 어림수("약 절반", "수십 건")로.
- 남의 개인정보(고객 이름, 학생 성적, 환자 정보)는 숫자로도 쓰지 않는다.
- 숫자를 지어내지 않는다. 세션에서 뽑은 숫자는 "제가 잰 것", 남의 숫자는 출처를 단다.

## 4. 발행 전 게이트

`scripts/check-gate.py`가 자동으로 보는 것과 사람이 보는 것을 나눈다. `[막힘]`은 고쳐야 넘기고, `[주의]`는 알려만 준다.

```
[ ] 제목: 도구명(한글)이 앞 20자 안에, 작업 명사와 대상이 있음. 숫자는 선택             (자동)
[ ] 제목: 기수 머리말, 시리즈 번호 없음. 주차·과제 표기는 본문으로                         (자동, 주차는 주의)
[ ] 첫 150자: 정의문 또는 답 + 숫자 하나 + 검색어. 메타 설명이 이 구간에서 나온다          (자동)
[ ] 날짜: 본문 안에 "2026년 9월 23일" 같은 절대 날짜 한 번 이상                           (자동)
[ ] 숫자: 하나마다 출처 또는 "제가 잰 것". 지어낸 숫자 0                                  (사람)
[ ] 작성자 신호: 닉네임과 입장 한 줄. 첫 H2 뒤나 하단, 맨 앞은 아님                         (자동)
[ ] 이미지: 실제 화면 1장 이상 권장, alt에 핵심 정보                                       (주의+사람)
[ ] 막힌 지점: 처음 시도가 안 된 이유 하나와 바꾼 계기                                    (사람)
[ ] 재현: 따라 할 프롬프트 1개 또는 3~5단계 순서                                          (사람)
[ ] 한영 병기: 핵심 도구명이 리드·정의문·H2 중 한 곳에 양쪽 표기                           (자동)
[ ] 틀 이름만 단 소제목 0: "소개", "한줄 요약"만 달랑 쓰지 않음. "소개: ○○"는 통과          (자동)
[ ] 헤지 0, 줄표 0, 격언 맺음("A와 B는 다르다") 1회 이하                                   (자동)
[ ] 초안 찌꺼기 0: 자리표시, 게시판 양식 안내문, AI 시점("사용자가"), 발행 메모             (자동)
[ ] 숫자 대조: 제목·첫 문단·본문·표·캡션의 같은 숫자가 다 같음                             (사람)
[ ] 재료 여덟 가지: 요청 원문, 막힌 순간, 바꾼 한 마디, 전후 숫자, 시간·돈, 모델, 결과물, 아직 안 된 것  (사람)
[ ] 남이 못 여는 링크 0, 사용자 경로 0, 이미지 속 개인정보 0                               (자동+사람)
```

## 4-1. 베터모드 형식 규칙 (지피터스 게시판 기준)

- **표는 목록으로.** 베터모드가 `<table>`에 테두리·여백을 안 줘서 셀이 붙어 나온다. 짧은 2열 대조만 표로 남기고 3열 이상은 목록. `- **전**: 40분 · 손으로 복사`
- **물결표 금지.** `2~4주`가 취소선으로 파싱돼 숫자가 사라진다(실제 사고: "24주"로 표시). 범위는 말로: "2주에서 4주", "서너 주".
- **줄표 금지.** em dash, en dash 전부. 제목·H2·본문·목록·캡션·alt 모두. 콜론이나 쉼표로.
- **볼드 경계에 문장부호·기호 금지.** `**"..."**`, `**48%**에서`처럼 여는 `**` 뒤나 닫는 `**` 앞에 따옴표·괄호·백틱·%·원이 오면 별표가 그대로 보인다. `**48% 확률로**`처럼 옮긴다.
- **메타 설명은 본문 앞 200자를 자른 것이고, 발행 후 못 바꾼다.** 앞 150자에 정의·검색어·숫자. 작성자 소개·인사·행사 안내·인용 블록을 맨 앞에 두지 않는다.
- **이미지 속 숫자는 본문에도 쓴다.** 크롤러와 AI는 이미지 속 글자를 읽는다고 가정할 수 없다.
- **H1은 제목 하나뿐.** 소제목은 H2·H3.
- 게시판 날짜는 "3달 전"처럼 상대 표기로 보인다. **본문 안 절대 날짜**가 AI에겐 유일한 날짜 신호다.
- JSON-LD·FAQ 스키마는 베터모드가 벗겨낸다. 시간 쓰지 않는다.

## 4-2. 모바일 가독성

멤버 글은 대부분 폰으로 읽힌다.

- 문단은 2~3문장, 260자 이하.
- H2는 400~800자마다 하나. H2 사이에 문단 4개를 넘기지 않는다.
- 목록 항목은 1~2줄. 번호 목록 전체가 길어도 문단 260자 규칙엔 걸리지 않는다.
- 코드블록은 5줄 이하. 요청 원문 블록만 8줄까지(빈 줄 빼고). 긴 로그는 캡처로.
- 카드·도식은 세로 한 열, 폭 520~560px, 글자 28px 이상, 한 장에 생각 하나(30자 이내).
- 섹션 끝 문장이 결론이어야 스크롤이 멈춰도 읽힌다.

## 5. 답을 안 해도 글이 나온다

- 질문에 전부 "알아서 해줘"여도 세션·프로필 기본값으로 글을 완성한다. 제목, 정의문, 숫자, 날짜, 작성자 신호는 사람 손 없이 채워진다.
- 캡처가 0장이면 막지 않는다. playwright가 있으면 카드로 대신하고, 없으면 "찍으면 좋을 장면" 목록만 남긴다.

## 6. 검색 수요가 없는 주제

1. **도구로 다시 잡기.** 개인 사연이라도 쓴 도구는 있다. "우리 반 알림장 정리"는 검색이 없지만 "챗GPT로 알림장 정리"는 있다. 도구 이름을 앞세운 제목 대안을 내고, 사연은 본문으로 내린다.
2. **기록형.** 그래도 없으면 검색 조사를 건너뛰고 `content_class: record`로 표시한다. 정의문·날짜·작성자 신호는 그대로 넣는다. AI 답변 엔진은 구체적 질문에 이런 글을 인용할 수 있다.
