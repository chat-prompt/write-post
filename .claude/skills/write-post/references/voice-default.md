# 지피터스 기본 문체 (2026-09-18 스냅샷)

첫 실행에서 "글이 3편 미만"이거나 문체 추출을 건너뛸 때 쓰는 기본값. 개인 문체 원본에서 남에게 적용해도 되는 규칙만 추렸다. 개인 문체 파일이 만들어지면 그쪽이 우선한다.

## 이렇게 쓴다

1. `~어요`체가 주력. 사실 전달 문장도 `~어요`로. `~니다`는 섞어 쓰되 같은 길이의 `~니다` 문장을 세 개 이상 나열하지 않는다.
2. 첫 문장은 장면이나 답으로 시작한다. "오늘은 ~에 대해 알아볼게요"처럼 주제 설명으로 열지 않는다.
3. 1인칭은 `제가`, `저`. `내가`는 따옴표 안 혼잣말에서만.
4. 짧게 끊고 결론이 앞에 온다. 한 문장에 정보 하나.
5. 문단은 2~3문장을 붙인다. 한 문장씩 떨어뜨리면 연출 티가 난다.
6. 독자를 부르는 말("~하실 텐데요")은 한 편에 한 번이면 충분하다. 안 써도 된다.
7. 취재 과정을 절차로 쓰지 않는다. ❌ "공식 페이지를 열어 확인했습니다" → ⭕ "제 계정으로 하나씩 눌러봤어요". 출처는 확인일 줄에 적는다.
8. 비유는 한 편에 하나까지. 추상 형용사("최고의", "탁월한", "놀라운")는 쓰지 않는다.
9. 느낌표는 한 편에 2개 이하. 이모지는 쓰지 않는다.
10. 10대도 60대도 읽는다. 줄임말·유행어·업계 은어를 쓰지 않고, 낯선 용어는 처음 나올 때 한 줄로 푼다("MCP는 AI에 도구를 꽂는 규격이에요").

## 쓰지 않는다

- 줄표 `—` `–`. 콜론이나 쉼표로 바꾸고 범위는 말로("2주에서 4주").
- `박습니다`·`박힙니다`·`못 박다` 계열 → "들어갑니다", "적어둡니다".
- `첫째·둘째·셋째`.
- `그리고`로 문장 잇기 → `근데`, `그래서`, `하나 더,`.
- 삼분할 정리("세 가지로 나뉩니다")와 대구법("A가 아니라 B") 남발. 대구법은 한 편에 1회.
- 헤지: "~일 수도", "~인 것 같습니다". 모르는 건 모른다고 쓴다.
- 격언으로 맺기: "A와 B는 다르다", "결국 본질은 ~다". 배운 점은 그 글에서 실제로 일어난 일로 쓴다.
- 3인칭·AI 시점: "사용자가 물었다", "이유를 물었더니 답은 ~였습니다". 작성자가 1인칭으로 쓴다.
- AI 출력 통째로 붙이기. 5줄 넘으면 핵심 줄만 인용하고 나머지는 말로.

## 사람이 쓴 표시 (베스트 사례에서)

- AI에게 친 말은 오타까지 원문 그대로.
- 막힌 순간의 감정 한 줄("최악이다", "또 실패할까봐 조마조마했어요").
- 모르는 걸 모른다고, 안 된 걸 안 됐다고. "솔직하게, 아직 안 된 것"은 신뢰를 올린다.
- 괄호 속 혼잣말과 작은 유머는 한 편에 두세 번까지.

## 도구 후기를 쓸 때

- 무료 플랜 짧은 실험으로 도구를 단정하지 않는다. 리드에 "무료 플랜 기준, N분 써본 결과"를 밝힌다.
- 결론은 도구 평가가 아니라 용도 판단으로. ❌ "이 도구는 별로다" → ⭕ "이 일에는 과분했다".
- 잘한 것을 먼저 모아 적고, 비용이 컸다면 내 지시 때문인지 도구 때문인지 갈라 쓴다.
- 제목에 `실패기`·`후기`·`써보기` 같은 소감형 말을 쓰지 않는다 → 도구명 + 작업 명사(`사용법`·`자동화`·`설정`·`실측`).
- 한 일을 "안 했다"고 반성하지 않는다. 실제로 안 한 일만 반성으로 쓴다.

## 분위기 문단 ("말투 바꿔 줘"라고 했을 때만. 고른 번호를 voice.md 끝에 그대로 붙인다)

1. **짧고 간결하게.** 결론이 첫 줄에 온다. 문단은 세 줄을 넘지 않는다. 한 문장에 생각 하나. 수식어보다 숫자. 접속사로 문장을 잇지 않고 끊는다.
2. **친절하고 재밌게.** 어요체로 말 걸듯 쓴다. 막힌 순간에는 기록에 있는 내 말과 그때 기분 한 줄을 그대로 둔다. 농담은 첫 문단 둘째 줄부터, 제목과 첫 문장에는 넣지 않는다. 느낌표는 글에 하나까지.
3. **시크하고 프로페셔널하게.** 습니다체. 이모지·감탄사·의성어 없이 사실과 결과만 쓴다. 문장 길이를 섞어 같은 길이의 "~니다"가 세 번 연속되지 않게 한다. 감상 대신 숫자와 판단 근거.
4. **신뢰도 있고 진중하게.** 숫자마다 잰 방법이나 출처를 붙이고, 날짜는 "2026년 9월 28일 기준"처럼 확인일을 쓴다. 확실하지 않은 건 "확인 못 했다"라고 쓴다. 기대치는 "기대"라고 표시한다.
기본은 이 문서 위쪽 "이렇게 쓴다"다. 번호를 고르지 않으면 그대로 간다.
