# 구글 상위 300페이지에서 나온 규칙 (2026-09-28)

AI 검색어 30개(지피터스 GSC 상위 20개 + 멤버 과제글이 겨냥할 10개)의 구글 자연 검색 상위 10개, 300페이지를 내려받아 분석한 결과다. 원자료와 전체 보고서는 저장소 `_analysis/serp300-2026-09-28.md`. 여기엔 글을 쓸 때 지킬 것만 둔다.

## 상위 글은 이렇게 생겼다

| 항목 | 상위 300 | 1~3위 | 지피터스 글 16편 |
|---|---|---|---|
| 제목 길이 | 중앙값 33자 | 32자 | 36자 |
| 검색어가 제목 앞 10자 안 | 80% | 79% | 94% |
| 첫 문단에 검색어 / 정의문 | 67% / 50% | 64% / 49% | 81% / 75% |
| 본문 글자 수(공백 제외) | 중앙값 4,100자, 25% 분위 2,600자 | 4,000자 | 3,300자, 짧은 3편은 8~10위 |
| H2 수 / 검색어 든 H2 비율 | 6개 / 40% | 5개 / 46% | 5개 / 30% |
| 이미지 | 5장 | 6장 | 2장 |
| 목록 있음 | 80% | 77% | |
| 2026년 발행 | 78% | 78% | 88% |

- AI 개요는 30개 검색어 전부에 떴다. 자연 검색 1위도 화면에선 AI 개요 아래다. 정의문 한 줄이 AI 개요 인용 재료다.
- 길이·H2 수·이미지 수와 순위의 상관은 0에 가깝다. 다만 **2,000자 미만 개인 글이 1~3위에 든 사례는 없다.** 7,000자 넘는 장문은 오히려 4~10위에 많다.
- 연도(2026)와 "완벽 가이드"는 4~10위에 더 많다. 「[대괄호]」로 시작하는 제목은 1~3위에 1%.
- 도구명 단독 검색어(에어테이블, dify, 리모션)는 1위가 거의 공식 페이지다. 노릴 자리는 2~3위이고 "○○란? 설치, 사용법" 설명형이 들어간다.
- "사용법·활용법·자동화" 검색어는 공식 문서가 적어 개인 글이 1위에 자주 든다(네이버 블로그 6건, 기업 블로그 6건).
- "사례·자동화" 검색어(ai 자동화 사례, n8n 자동화, 챗gpt 엑셀 자동화)는 공식 문서 0%로 전부 블로그 자리인데 **지피터스 글이 0건**이다. 멤버 과제글이 정확히 이 유형이다. 제목과 H2에 "자동화", "사례"가 있어야 잡힌다.
- 경험 신호는 제목·첫 문단이 아니라 본문 안에서: 상위 글은 "직접·써봤·실제로" 5~6회, 단위 붙은 숫자 5개. 첫 문단을 "저는 ~해봤어요"로 여는 글은 14%뿐이고 "후기" H2는 4~10위에 더 많다.

## 지피터스 안에서 무엇이 순위를 갈랐나

같은 gpters.org 도메인인데 글 모양으로 갈렸다. 도메인 힘이 아니라 글 하나하나의 모양이 순위를 정한다는 뜻이다.

| | 1~3위 7편 | 8~10위 3편 |
|---|---|---|
| 누가 썼나 | 에디터 총정리형 | 멤버 과제글 |
| 제목 | 검색어로 시작. "클로드 이미지 생성 사용법 총정리", "힉스필드 무료체험, 24시간 뒤 자동결제됩니다" | "[Claude skills 써보기] 말로만 듣다가 처음 해봤습니다", "옵시디언/클로드코드 (청강후기)", "리모션 직접 해보기 [미니사례]" |
| 본문 | 2,200~5,800자 | 773~1,012자 |
| 첫 문단 | 정의문 + 검색어 | 인사·소감 |
| H2 | 4~11개 | 0~3개 |

멤버 글이 못 올라가는 게 아니다. 같은 검색어("클로드 스킬")에서 지피터스 글이 10위에 있는데, 그 위 2위는 이랜서 블로그의 "Claude Skills 사용법, 이렇게 쓰면 결과물이 완전히 달라집니다"(5,900자, 캡처 29장)다. 멤버 글도 **검색어로 시작하는 제목 + 2,500자 + 정의문 첫 문단**이면 같은 자리를 노릴 수 있고, "자동화·사례" 검색어는 아직 지피터스 글이 0건인 빈자리다.

## 그래서 글에 지킬 것

1. **제목 25~35자.** 검색어(도구명 한글)로 시작 + 작업 명사(사용법·자동화·만들기·설치·정리·N가지·사례) + 구체 약속 하나. 연도·"완벽 가이드"·대괄호 머리말은 쓰지 않는다.
2. **첫 문단 120자 안에 검색어와 정의문.** "○○는 ○○하는 도구예요"는 새 도구가 아니어도 넣는다. 베터모드는 첫 문단이 검색 설명문이 되니 첫 문단을 120자 안에서 끊는다(상위권 설명문 100~120자, 지피터스는 205자).
3. **본문 2,500자 이상, 목표 3,000~4,000자(공백 제외).** 2,000자 미만이면 검색 상위는 어렵다고 발행메모에 적고, 그래도 지어내지 않는다. 채우는 재료는 지어내지 않고 기록에서 가져온다: AI가 한 일의 순서, 설정값·파일·명령, 시도한 순서와 안 된 이유, 결과 화면 묘사, 실제로 받은 질문. 7,000자를 넘기지 않는다.
4. **H2 5~7개, 그중 2~3개에 도구명이나 작업어.** 내용으로 쓰되 검색어를 품는다: "클로드 코드로 시세 지도 만든 순서", "리모션 설치에서 막힌 것".
5. **목록은 꼭. 표는 쓰지 않는다**(베터모드에서 깨진다). 비교·요금제 글은 항목별 목록으로.
6. **캡처 3장 이상을 목표로.** 상위권 중앙값 5~6장, 지피터스 2장. 필수는 아니지만 사례글은 캡처가 경험 증거다.
7. **실제로 받은 질문이 있으면 "자주 묻는 질문" H2에 2~3개.** 없으면 만들지 않는다. 지피터스 1~3위 7편 중 4편에 있었다.
