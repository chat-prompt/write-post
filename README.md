# write-post

지피터스 스터디 멤버를 위한 **사례 게시글 작성 스킬**입니다. AI로 작업한 기록을 정리해 사례글로 써 줍니다. `/write-post` 한 번이면 본문 초안과 발행메모까지 나옵니다.

## 무엇이 나오나요

- **본문 초안**. 검색과 AI 답변에서 발견되기 좋은 제목과 첫 문단이 들어갑니다.
- **발행메모**. 태그, 이미지 넣을 위치, 올리는 방법, 1분 발표용 5줄이 들어갑니다.
- **작업 기록 정리**. 글의 재료가 된 요청, 막힌 순간, 숫자, 결과물을 모아 줍니다.
- 집중해서 하면 한 편에 10분 안팎입니다. 처음엔 설정이 있어 조금 더 걸려요.

## 누구에게 맞나요

- 과제로 AI 작업을 했고, 그걸 사례글로 정리해야 하는 스터디 멤버
- 코드를 못 읽어도 됩니다. 명령 한 줄 붙여 넣을 수 있으면 충분합니다.
- 클로드 코드, 코덱스, 제미나이 CLI 같은 도구로 작업한 기록이 있으면 좋습니다.
- 챗GPT나 클로드 웹에서 한 작업도 됩니다. 대화를 붙여 넣으면 돼요.

## 설치: 링크 하나 붙여 넣기

쓰고 있는 AI 도구(클로드 코드, 코덱스, 제미나이 CLI)를 열고 그대로 붙여 넣으세요.

```
https://github.com/chat-prompt/write-post 이 스킬 설치해 줘
```

AI가 아래 "AI 에이전트가 설치할 때"를 읽고 알아서 깔고, 그 자리에서 바로 글쓰기를 시작해요. 과제를 하던 창에 붙여 넣으면 가장 좋습니다. 그 창의 작업 기록을 그대로 재료로 쓰니까요.

다음부터는 `/write-post`라고 치면 됩니다. 터미널에서 직접 깔고 싶으면 아래 [직접 설치](#직접-설치-터미널)를 보세요.

## 쓰는 방법

작업한 폴더에서 AI 도구를 열고:

```
/write-post
```

코덱스처럼 슬래시 명령이 없는 도구에서는 "write-post 스킬로 사례글 써줘"라고 하면 됩니다.

### 글이 만들어지는 흐름

1. **작업 기록 읽기**(자동). AI와 나눈 작업 기록에서 글에 쓸 재료를 찾습니다.
2. **확인 한 번**. 찾은 것(요청 원문, 막힌 순간, 숫자, 결과물)을 보여 줍니다. 제목 3개 중 하나 고르고, 이 글에서 제일 하고 싶은 말, 전에는 어떻게 했는지, 이미지(캡처·AI 그림·없음), 빈 칸만 답하면 돼요.
3. **초안과 발행 전 점검**(자동). 본문과 발행메모가 나옵니다.
4. **붙여 넣기**. "본문 복사해 줘"라고 하면 그림까지 서식 그대로 복사돼요. 지피터스 글쓰기 화면에 붙여 넣고 태그만 고르면 됩니다.

발행 버튼은 직접 누릅니다.

### 내가 해야 하는 일

1. 처음 설정 한 번(질문 세 개에 답하고, 스터디 태그 고르기)
2. 글마다 어느 스터디 글인지 한 번 누르기
3. 추천받은 **제목 하나 고르기**
4. 뽑아 온 **숫자와 원문 확인하기**(틀린 것만 고치면 돼요)
5. 알려 준 장면 **캡처해 오기**(못 찍어도 글은 나옵니다. AI가 그림을 그려 줄 수도 있어요)
6. 발행 전 태그 확인, 캡처를 줬으면 가릴 곳 승인

검색어 조사, 제목 만들기, 개인정보 가리기, 발행 전 점검, 태그 확인은 스킬이 합니다.

### 처음 한 번만 묻는 것 (한 메시지)

- 지피터스 닉네임(프로필에 보이는 그대로)
- AI 스터디를 듣고 있다면 몇 기, 어떤 스터디인지(예: 24기 업무자동화). 이름을 정확히 몰라도 돼요. 스킬이 게시판 태그에서 찾아 맞는지 한 번 물어요. 여러 개 들으면 다 적고, 글마다 어느 스터디 글인지 한 번 눌러요.
- 본인 소개 한 줄(예: 평범한 회사원, 동네에서 카페 운영, 두 아이 키우며 AI 공부 중, 퇴직하고 AI 배우는 중). 회사나 가게 이름, 실명은 안 적어도 됩니다.

말투는 묻지 않아요. 지피터스에 올린 글이 3편 이상이면 그 글의 말투를 알아서 따라가고, 없으면 읽기 편한 기본 말투로 써요. 원하면 "말투 바꿔 줘"라고 하면 됩니다.

## 더 해 볼 수 있는 것 (선택)

- "말투 바꿔 줘"
- "카드 만들어 줘" (전후 숫자 카드)
- "폰으로 미리 보여 줘"
- "내 글로 문체 뽑아 줘"
- "프로필 다시 설정"
- "스킬 업데이트해 줘"
- AI 그림을 쓰고 싶으면 처음 한 번 구글 API 키를 붙여 넣어요. API 키는 공짜고, 그림은 한 장에 50원쯤 들 수 있어요.

## 직접 설치 (터미널)

### Mac / Linux

```bash
curl -fsSL https://raw.githubusercontent.com/chat-prompt/write-post/main/install_mac.sh | bash
```

### Windows (PowerShell)

```powershell
iwr -useb https://raw.githubusercontent.com/chat-prompt/write-post/main/install_win.ps1 | iex
```

설치할 때 도구(Claude Code, OpenCode, Codex CLI, Gemini CLI, Antigravity)와 위치(전역 또는 현재 폴더)를 고릅니다. 예전 버전이 깔려 있어도 같은 명령으로 덮어쓰면 최신이 됩니다.

설치 후 `/write-post` 명령은 **AI 도구를 다시 켠 뒤**부터 보입니다. 다시 켜기 싫으면 그 창에 "write-post 스킬로 사례글 써줘"라고 치면 바로 됩니다. 그 뒤로는 스킬이 시작할 때 새 버전이 있으면 "지금 받을까요?"라고 물어요.

## AI 에이전트가 설치할 때 (사람은 안 읽어도 됩니다)

메뉴를 묻지 않는 명령이다. 지금 실행 중인 도구 이름을 넣고, 전역으로 설치한다. 설치 뒤 `SKILL.md`가 있는지 확인한다. 다른 것은 설치하지 않는다.

**설치가 끝나면 다시 시작하라고 하지 않는다.** 사용자는 방금까지 이 창에서 과제를 하던 사람이다. 설치한 `SKILL.md`를 읽고 그 내용대로 **이 창에서 바로** 사례 글 쓰기를 시작한다(같은 창에서 이어서 돌리면 스킬이 앞의 과제 기록을 그대로 재료로 쓴다). 슬래시 명령 `/write-post`는 다음에 도구를 새로 켰을 때부터 쓸 수 있다고 마지막에 한 줄만 알려 준다.

```bash
# Mac / Linux. 도구: claude | codex | gemini | opencode | antigravity | all (쉼표로 여러 개)
curl -fsSL https://raw.githubusercontent.com/chat-prompt/write-post/main/install_mac.sh | bash -s -- claude global
ls ~/.claude/skills/write-post/SKILL.md
```

```powershell
# Windows
$env:WP_TOOLS="claude"; $env:WP_SCOPE="global"; iwr -useb https://raw.githubusercontent.com/chat-prompt/write-post/main/install_win.ps1 | iex
Test-Path "$env:USERPROFILE\.claude\skills\write-post\SKILL.md"
```

코덱스는 `codex`, 제미나이 CLI는 `gemini`. 어느 도구인지 모르면 사용자에게 한 번 묻는다.

## 있으면 더 좋은 것 (없어도 됩니다)

- **node**: 세션을 읽어 재료를 뽑고, 게시판 태그를 확인하는 스크립트가 돌아갑니다. 없으면 스킬이 직접 읽어서 조금 느려집니다.
- **python**: 발행 전 자동 점검과 캡처 가리기(Pillow). 없으면 체크리스트로 직접 점검합니다.
- **playwright**: "카드 만들어 줘", "폰으로 미리 보여 줘"라고 할 때만 씁니다.

## 이 스킬이 지키는 것

**검색에 걸리는 제목.** 도구명으로 시작하고, 도구를 두 개 이상 썼으면 둘 다 넣고, 연동·만들기·자동화 같은 작업 명사와 대상을 붙입니다. 역대 베스트 사례 185편의 구글 성과에서 가장 강했던 신호예요. 스터디 기간엔 한 주에 수백 편이 올라오기 때문에, "클로드 코드 사용법"처럼 넓은 제목은 서로 겹쳐서 묻힙니다.

```
❌ 드디어 해냈다! 나만의 첫 자동화 도전기
⭕ 헤르메스에 제미나이 노트북 연동하기
⭕ 클로드 코드로 네이버 부동산 시세 지도 만들기
```

**AI가 인용하는 첫 문단.** 첫 문단(120자 안)이 검색 결과 설명문이 되고, 발행 후엔 못 바꿉니다. 여기에 정의 한 줄, 숫자, 도구명, 날짜를 넣습니다.

**내 글로 보이는 본문.** AI에게 친 말 원문, 막혔던 순간과 바꾼 한 마디, 직접 잰 숫자, 결과물 링크, 아직 안 된 것, 쓴 사람의 사정이 들어갑니다. 세션에서 먼저 찾고 빈 칸만 물어봅니다. "한줄 요약", "소개"처럼 틀 이름만 단 소제목 대신 그 글의 내용을 소제목으로 씁니다. 게시판 기본 틀(소개 / 진행 방법 / 결과와 배운 점)을 원하면 "소개: ○○"처럼 내용을 붙여 씁니다.

**이어 쓰는 글과 참고한 자료.** 주차 과제로 이어 쓰면 지난 글을 링크하고 이번 주에 달라진 것부터 씁니다. 참고한 공식 문서·강의·멤버 글이 있으면 맨 끝 "참고한 자료"에 남깁니다.

**개인정보.** 폴더 경로, 이메일, API 키, 남의 이름은 본문과 캡처에서 가립니다. 로그인해야 열리는 링크는 뺍니다. 내 매출·수입 같은 숫자는 공개할지 물어봅니다.

**지피터스 게시판 형식.** 표 대신 목록, 물결표·줄표 금지처럼 게시판에서 깨지는 것을 미리 막습니다.
