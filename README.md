# write-post

지피터스 스터디 멤버를 위한 **사례 게시글 작성 스킬**입니다. AI로 작업한 기록을 정리하고, 구글·네이버 검색과 챗GPT·제미나이·클로드 같은 AI 답변에 잘 걸리는 구조로 사례글을 써 줍니다.

`/write-post` 한 번이면 됩니다. 멤버가 하는 일은 세 가지예요.

1. 스킬이 추천한 **제목 하나 고르기**
2. 스킬이 세션에서 뽑은 **숫자 확인하기**
3. 스킬이 알려준 장면 **캡처해 오기**

검색어 조사, 제목 만들기, 문체 맞추기, 개인정보 가리기, 발행 전 점검은 스킬이 합니다.

---

## 설치

### Mac / Linux

```bash
curl -fsSL https://raw.githubusercontent.com/chat-prompt/write-post/main/install_mac.sh | bash
```

### Windows (PowerShell)

```powershell
iwr -useb https://raw.githubusercontent.com/chat-prompt/write-post/main/install_win.ps1 | iex
```

설치할 때 도구(Claude Code, OpenCode, Codex CLI, Gemini CLI, Antigravity)와 위치(전역 또는 현재 폴더)를 고릅니다. 예전 버전이 깔려 있어도 같은 명령으로 덮어쓰면 최신이 됩니다.

설치 후에는 **쓰고 있는 AI 도구를 다시 시작**해야 스킬이 보입니다.

### 있으면 더 좋은 것 (없어도 됩니다)

- **python**: 발행 전 자동 점검과 캡처 가리기. 없으면 스킬이 체크리스트로 직접 점검합니다.
- **node + playwright**: 전후 숫자 비교 카드, 폰 화면 미리보기. 없으면 건너뜁니다.

## 사용법

작업한 폴더에서 AI 도구를 열고:

```
/write-post
```

코덱스처럼 슬래시 명령이 없는 도구에서는 "write-post 스킬로 사례글 써줘"라고 하면 됩니다.

### 처음 한 번만 묻는 것

- 지피터스 닉네임 (프로필에 보이는 그대로)
- 기수와 스터디 (예: `24기 GEO실험실`, 게시판 태그 그대로)
- 어떤 입장에서 쓰는지 (회사원, 자영업, 창업, 프리랜서, 쉬면서 준비 중, 학생·주부 등. 회사나 가게 이름은 안 적어도 됩니다)
- 원하는 글 분위기

닉네임으로 예전에 쓴 글을 읽어 문체를 맞추고, 작성자 소개 한 줄을 만들어 둡니다. 다음부터는 바로 시작합니다.

### 흐름

```
Phase 1  작업 기록 정리
         AI 코딩 도구 세션을 읽어 DEVLOG.md를 만듭니다.
         챗GPT·클로드 웹에서 한 작업이면 대화를 붙여 넣으면 됩니다.
    ↓
Phase 2  기록 확인
         빠진 것, 빼고 싶은 것(회사 정보 등)을 말하면 고칩니다.
    ↓
Phase 3  사례글
         검색어 조사 → 제목 3개 중 고르기 → 숫자·캡처 확인
         → 개인정보 가리기 → 초안(AI_CASE_STUDY.md) → 발행 전 점검
         → 태그·올리는 방법 안내
```

## 이 스킬이 지키는 것

**검색에 걸리는 제목.** 도구명(한글·영문) + 구체적인 대상·업무 + 결과 숫자로 만듭니다. 스터디 기간엔 한 주에 수백 편이 올라오기 때문에, "클로드 코드 사용법"처럼 넓은 제목은 서로 겹쳐서 묻힙니다.

```
❌ 드디어 해냈다! 나만의 첫 자동화 도전기
⭕ 클로드 코드(Claude Code)로 세금계산서 엑셀 정리: 40분에서 3분으로
```

**AI가 인용하는 첫 문단.** 첫 150자가 검색 결과 설명문이 되고, 발행 후엔 못 바꿉니다. 여기에 답, 숫자, 도구명, 날짜를 넣습니다.

**내 글로 보이는 본문.** 직접 잰 숫자, 실제 캡처, 막혔던 순간, 쓴 사람의 입장이 들어갑니다. "한줄 요약", "소개"처럼 틀 이름만 단 소제목 대신 그 글의 내용을 소제목으로 씁니다. 게시판 기본 틀(소개 / 진행 방법 / 결과와 배운 점)을 원하면 "소개: ○○"처럼 내용을 붙여 씁니다.

**이어 쓰는 글과 참고한 자료.** 주차 과제로 이어 쓰면 지난 글을 링크하고 이번 주에 달라진 것부터 씁니다. 참고한 공식 문서·강의·멤버 글이 있으면 맨 끝 "참고한 자료"에 남깁니다.

**개인정보.** 폴더 경로, 이메일, API 키, 남의 이름은 본문과 캡처에서 가립니다. 로그인해야 열리는 링크는 뺍니다. 내 매출·수입 같은 숫자는 공개할지 물어봅니다.

**지피터스 게시판 형식.** 표 대신 목록, 물결표·줄표 금지처럼 게시판에서 깨지는 것을 미리 막습니다.

발행 버튼은 멤버가 직접 누릅니다.
